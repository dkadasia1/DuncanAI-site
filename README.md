# DuncanAI

DuncanAI is an AI Creative Studio starter website.

## Current version

Static HTML/CSS/JavaScript. It includes:

- AI image generation interface
- Image-to-video interface
- Text-to-video interface
- Edit/enhance placeholder
- Features, pricing, and documentation pages
- Responsive design

## Deploying to Vercel

This project does not require a framework or build command.

1. Upload all files to the root of the GitHub repository.
2. In Vercel, import the GitHub repository.
3. Use the default settings for a static site.
4. Deploy.

## Next steps

Connect secure server-side API endpoints for image and video generation. Never place private AI API keys directly in `script.js`.
